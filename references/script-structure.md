# Script Structure Reference — Telugish Scriptwriter

## Retention Architecture (Text-Based Diagram)

```
┌─────────────────────────────────────────────────────────┐
│  [0:00 - 0:20] HOOK                                     │
│  Bold claim, curiosity gap, shocking stat. NO greeting.  │
│  Creates open loop → viewer must watch to close it.     │
├─────────────────────────────────────────────────────────┤
│  [0:20 - 1:00] INTRO                                    │
│  Promise: "End of video, you'll understand X..."        │
├─────────────────────────────────────────────────────────┤
│  ┌─────────────────────────────────────────────────────┐│
│  │ SEGMENT 1 — Mini-hook → Deep dive → RH Q → Cliff   ││
│  │                   [RE-HOOK ~min 3-4]                ││
│  ├─────────────────────────────────────────────────────┤│
│  │ SEGMENT 2 — Mini-hook → Deep dive → RH Q → Cliff   ││
│  │                   [RE-HOOK ~min 6-7]                ││
│  ├─────────────────────────────────────────────────────┤│
│  │ SEGMENT 3 — Mini-hook → Deep dive → RH Q → Cliff   ││
│  │                   [MID-CTA ~min 9-11 — at natural break only]││
│  │                   [RE-HOOK ~min 12-13]              ││
│  ├─────────────────────────────────────────────────────┤│
│  │ SEGMENT 4 — Mini-hook → Deep dive → RH Q → Cliff   ││
│  │                   [RE-HOOK ~min 15-16]              ││
│  └─────────────────────────────────────────────────────┘│
├─────────────────────────────────────────────────────────┤
│  [CONCLUSION ~min 15-17]                                │
│  - Close open loop from hook                            │
│  - Big-picture takeaway                                 │
│  - [OPINION] labeled                                    │
│  - Comment-driver question                              │
├─────────────────────────────────────────────────────────┤
│  [OUTRO ~30 sec]                                        │
│  Value → like/share/sub → "love you so much" → sign-off │
└─────────────────────────────────────────────────────────┘

Re-hook frequency: [HOOK] → [~3 min] → [RE-HOOK] → [~3 min] → [RE-HOOK] →
[~3 min] → [MID-CTA] → [~3 min] → [RE-HOOK] → [~2 min] → [CONCLUSION]
```

## Timestamp Budget (17-19 min script at ~130 wpm for Telugu)

| Section | Time | Words | Purpose |
|---------|------|-------|---------|
| Hook | 0:00 - 0:20 | 100-150 | Open loop, bold claim, NO greeting |
| Intro | 0:20 - 1:00 | 150-200 | Promise, roadmap |
| Segment 1 | 1:00 - 4:30 | 450-650 | First deep dive with re-hook at ~3 min |
| Segment 2 | 4:30 - 8:00 | 450-650 | Second angle with re-hook at ~6-7 min |
| Segment 3 | 8:00 - 12:00 | 500-700 | Third angle + Mid-CTA (at narrative dip, ~min 9-11) |
| Segment 4 | 12:00 - 15:30 | 450-650 | Fourth angle with re-hook at ~13-14 min |
| Conclusion | 15:30 - 17:30 | 350-450 | Close loop, takeaway, opinion, comment-driver |
| Outro | 17:30 - 19:00 | 100-150 | Value → subscribe → sign-off |

Adjust segment count based on topic depth (3-6 segments). Shorter topics use fewer, deeper segments. Complex topics spread across 5-6 segments.

## Segment Types (Choose Based on Topic)

### Type A: Narrative/Storytelling Segment
Best for: Topics with a clear timeline or sequence of events (elections, scandals, investigations).

**Structure:**
1. Mini-hook: "Kani ee katha start avvadaniki mundu, oka chinna background cheppukovali..."
2. Background context (what led to this point)
3. The key event (what actually happened)
4. Rhetorical question: "Intaki ila enduku jarigindi?"
5. Analysis wrapped in storytelling: "Ee decision valla... ani impact undi"
6. Mini-cliffhanger: "Kani ee effect immediate ga kanipinchaledu... enduku ante..."

**Example topic fit:** "How Mamata Banerjee countered BJP in West Bengal"

### Type B: Data/Investigation Segment
Best for: Topics driven by numbers, reports, statistics (budgets, schemes, data leaks).

**Structure:**
1. Mini-hook: "Ippudu numbers lo choodandi..."
2. Stat reveal with source ("Election Commission data prakaram...")
3. Comparison stat (before/after, this year/last year)
4. Rhetorical question: "Ee difference emi cheptundi?"
5. Analysis of what numbers mean for Telugu audience
6. Mini-cliffhanger: "Kani ee numbers lo daggara unna story inka interesting..."

**Example topic fit:** "₹27,000 crores budget — where does the money go?"

### Type C: Comparison/Contrast Segment
Best for: Two sides of an issue, before/after, competing narratives.

**Structure:**
1. Mini-hook: "Oka pakka idi... inko pakka idi..."
2. Side A: their position, evidence, who supports it
3. Side B: their position, evidence, who supports it
4. Rhetorical question: "Evaru correct?"
5. Analysis: what's actually happening beneath the surface
6. Mini-cliffhanger: "Kani ground reality inko story cheptundi..."

**Example topic fit:** "BJP vs TDP in Andhra — who has the edge?"

## Segment Transitions (Bridge Sentences)

Use these to move smoothly between segments. NEVER transition abruptly.

| Transition Type | Bridge Sentence |
|----------------|-----------------|
| Related angle | "Idi ala undagaa, inkoka interesting angle entante..." |
| Deeper dive | "Kani ikkada aagipodam ledu. inka deep ga velte..." |
| Contradiction | "Kani oka pakka... and inko pakka reality..." |
| Time shift | "2019 nunchi 2026 varaku ... lo chaala change vachindi" |
| Perspective shift | "Ee angle nunchi chuste... kani normal public ki..." |
| Reveal incoming | "Ee analysis taruvata telisindi — mind block avvali!" |
| Question bridge | "Intaki ee situation lo asalu winner evaru?" |

## Retention Checkpoints

For each segment, ask:
- Does this segment have at least 1 curiosity gap?
- Is there a "what this means for YOU/Telugu audience" moment?
- Does the segment end with a reason to watch the next one?
- Would a Telugu current affairs viewer get bored here?

If the answer to any is "no" or "maybe," that segment needs a re-hook or tighter writing.
