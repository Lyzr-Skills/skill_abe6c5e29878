# Hook Templates — VR Raja's Opening Style

## Hook Golden Rules

- **NO greeting** — first word is the hook
- **Bold** (wrap in `**`)
- **Short** — 100-150 words, 20-30 seconds
- **Open loop** — viewer must watch to get closure
- **Telugish** — first sentence is in Telugish
- **Shock/surprise/curiosity** — makes viewer say "endhi?"

---

## Template 1: The Shocking Stat

**Structure:** `[BOLD: {shocking number} + {what it reveals}] → [So what? question] → [Promise]`

**When to use:** Topics where a specific number changes everything — election data, budget numbers, survey results, death tolls, fraud amounts.

**Examples:**
```
**91 lakshala voters mayam!** Ante ratriki ratri ekanga 91 lakhs mandi voters aa list lo nunchi enduku poyaru? Evaru teesesaru? Idi accidental kaadhu — planned move. Inka ee topic lo asalu twist ento telusukovalante, video complete choodandi.
```

```
**₹27,000 crores loan waived!** Kani evariki? Enduku? Ee amount chala states annual budget kante ekkuva. Evariki benefit? Evaru pay chestaru? Answer teliyali ante chustu undandi.
```

## Template 2: The Twist/Reveal

**Structure:** `[BOLD: {common belief} + {but actual truth}] → [Why everyone is wrong] → [Promise to reveal]`

**When to use:** Topics where public perception differs from reality — political narratives, popular myths, misunderstood policies.

**Examples:**
```
**Mana TV lo eppudo oka news ochindi — idi simple issue ani.** But ground reality completely different. Ee issue lo asalu jarigindi ento, evariki teliyani facts ento ippudu telustayi.
```

```
**Anta arustunnaru — inflation control lo undi ani.** Kani reality? Ground level prices chusthe... inkoka story kanipistundi. Numbers emi cheptayo choodandi — mind block avvali!
```

## Template 3: The Rhetorical Question

**Structure:** `[BOLD: {direct question to viewer}] → [Why they should care] → [Promise]`

**When to use:** Topics where the viewer already has curiosity — controversial issues, personal impact stories, things that affect daily life.

**Examples:**
```
**Neeku ardham ayindha — ee tax kotte scheme valla nee jeevitham ela marutundi?** Chala mandi impact gurinchi matladutunnaru kani... shaft vaipu evaru matladatledu. Ippudu telusukondi.
```

```
**Oka vote difference entha pedda?** Meeru anukuntunna... kani 2026 lo oka single vote difference chala places lo government ni marchipochindi. Ela? Chudandi.
```

## Template 4: The "Nobody Is Talking About"

**Structure:** `[BOLD: {important topic} + ikkada evaru matladatledu] → [Why it's important] → [Promise to expose]`

**When to use:** Under-reported stories, silent crises, ignored angles — topics that should be news but aren't.

**Examples:**
```
**Oka pedda scam nadustundi — kani mana media lo coverage Zero!** Enduku evaru matladatledu? Evari interests involve ayyayi? Ippudu ee video lo full expose.
```

```
**India lo silent crisis — evaru matladatledu, evaru recognize cheyatledu.** Kani idi mana future generations ni directly impact chestundi. Meeru telusukovali.
```

## Template 5: The "Did You Know?"

**Structure:** `[BOLD: {unknown / surprising fact}] → [Telusaa? question] → [Context of why it matters]`

**When to use:** Topics with very specific, little-known facts. Works best when the fact genuinely surprises most viewers.

**Examples:**
```
**India oka secret alliance build chestundi — telusaa?** Idi news lo raaledu, evaru matladatledu. Kani idi entire South Asia power dynamics marchipotundi.
```

```
**Ee year budget lo oka clause undi — media evaru notice cheyaledu.** Telusaa? Ee clause valla major policy shift avutundi. Detailed analysis mundu.
```

## Template 6: The Comparison/Contrast

**Structure:** `[BOLD: Side A vs Side B] → [Why the difference matters] → [Promise to analyze]`

**When to use:** Comparison topics — two states, two policies, two time periods, two politicians.

**Examples:**
```
**Oka state — oka CM, oka policy. Inko state — inkoka CM, inkoka policy.** Result? Same country, totally different outcomes. Evaru better? Numbers lo chudandi.
```

```
**2019 budget vs 2026 budget — oka comparison.** 7 years lo entha change ayyindi? Inka enta change undi? Numbers prove chestayi.
```

## Template 7: The Future Warning

**Structure:** `[BOLD: {future event / prediction}] → [Why it affects the Telugu viewer] → [Promise of analysis]`

**When to use:** Topics about upcoming events, future risks, upcoming elections, policy changes coming into effect.

**Examples:**
```
**2026 lo India oka big change ki face avutundi.** Idi politics, economy, mariyu mana daily life mothanni affect chestundi. Ippude prepare avvali. Ela? Telusukondi.
```

```
**Coming 6 months lo oka major economic shift vastundi.** Chala mandi chustunnaru kani ardham cheskotledu. Idi mana Telugu states ni ela impact chestundo telusukondi.
```

## Template 8: The Opinion Challenge

**Structure:** `[BOLD: {controversial opinion}] → [Why you might disagree] → [Evidence-based challenge]`

**When to use:** Topics where VR Raja takes a strong opinion against common belief — opinion-heavy analysis.

**Examples:**
```
**Nenu antaanu — ee policy complete failure!** Meeru anukovachu success ani. Kani evidence different story cheptundi. Disagree aithe, comment lo argue cheyandi.
```

```
**Evaru manchi opposition ledu ani anukuntunnara?** Nenu antaanu — undi, kani meeku teliyadu. Ee video lo prove chestaa.
```

## Template 9: The Personal Story

**Structure:** `[BOLD: {personal / relatable scene}] → [Why this connects to bigger issue] → [Promise]`

**When to use:** Topics that start with a human angle before zooming out to systemic analysis.

**Examples:**
```
**General ga chaala mandi nannu adigina question — "Anna, future India lo safe aa?"** Exact answer cheppalante... situation complex. Kani oka perspective. Vidam chuddam.
```

```
**Nenu recent ga oka person kalisaanu — IT job lo 15 years, ippatiki unemployed.** Oka story, but oka entire generation ki mirror. Ela jarigindi? Ee video lo analysis.
```

## Template 10: The Process/Investigation

**Structure:** `[BOLD: {topic} + deep investigation / research] → [What viewer will learn] → [Promise of exclusive info]`

**When to use:** Topics where VR Raja has done original research — data analysis, fact-checks, investigations.

**Examples:**
```
**Chala mandi nannu adigina video — 2026 West Bengal Elections analysis.** Idi just oka state election kaadhu, India mothaniki oka pedda case study. Detailed analysis mundu.
```

```
**Ma team oka 3-month research chesindi — ee topic meeda.** Ippudu full report. Evari interest involve ayyayi? Ela jarigindi? Evarki benefit? Anni telustayi.
```

## Hook Selection Guide by Topic Type

| Topic Type | Best Template | Why |
|------------|--------------|-----|
| Election/political analysis | 1 (Shocking Stat) or 7 (Future Warning) | Numbers create urgency |
| Budget/economy | 1 (Shocking Stat) or 8 (Opinion Challenge) | Data + opinion keeps engagement |
| Corruption/scam | 4 (Nobody Talking About) or 2 (Twist) | Expose framing drives curiosity |
| Social issue | 9 (Personal Story) or 3 (Rhetorical Q) | Emotional connection needed |
| International affairs | 5 (Did You Know) or 7 (Future Warning) | Unknown info hooks viewer |
| Comparison (states/leaders) | 6 (Comparison) or 2 (Twist) | Contrast creates natural curiosity |
| Tech/policy change | 1 (Shocking Stat) or 5 (Did You Know) | Specific facts work best |
| Opinion piece | 8 (Opinion Challenge) or 3 (Rhetorical Q) | Controversy drives comments |
| Investigation | 10 (Process) or 4 (Nobody Talking) | Exclusivity hooks viewer |
| General current affairs | 2 (Twist) or 7 (Future Warning) | Broader appeal, less niche |
